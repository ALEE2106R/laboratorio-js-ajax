# Laboratorio de JavaScript y AJAX

Alexander Reyes · Desarrollo de Aplicaciones en Red

Cuatro ejercicios JavaScript y un visor AJAX con URL inicial, contenidos, estados, cabeceras y código HTTP.

## Publicación

Activar Settings → Pages → Deploy from a branch → main → /(root). La dirección prevista es https://alee2106r.github.io/laboratorio-js-ajax/; su disponibilidad debe comprobarse después del despliegue.

## Archivos

- index.html: interfaz
- estilos.css: presentación
- logica.js: cuatro ejercicios
- app.js: formularios y XMLHttpRequest
- respuesta.txt: recurso de prueba

## Ejecución local

`python -m http.server 8000` y abrir http://localhost:8000.
